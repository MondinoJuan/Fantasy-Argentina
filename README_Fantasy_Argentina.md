# Fantasy Argentina

La documentación vigente se mantiene en `README.md`, `Reglas.md`, `Paso a paso.md`, `docs/SEGURIDAD.md` y `docs/ECONOMIA_Y_PLANTELES.md`.

Este archivo anteriormente duplicaba reglas con otros tamaños de mercado y plazos. Se unificó para evitar contradicciones. Mercado: 3 jugadores por participante; cierre automático: último inicio +5h, con reintento +4h si sigue en curso; once titulares y cinco suplentes de capacidad, con once jugadores asignados al comenzar; capitán con puntos dobles; cláusula inicial igual al valor traducido + 3M y conservación de los aumentos por torneo.

La configuración existente del torneo está documentada en `Paso a paso.md`, distinguiendo implementación actual y correcciones pendientes.
